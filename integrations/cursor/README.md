# Cursor Integration

Uses MCP server only (Cursor doesn't support hooks).

## Install

```bash
bash install.sh   # from repo root: bash integrations/windsurf/install.sh
# or manually copy integrations/cursor/mcp.json to ~/.cursor/mcp.json
```

## Verify

Open Cursor → Settings → MCP → you should see `moma` listed with 7 tools.

## Available tools in Cursor

- `moma_memory_search` — search your memory store
- `moma_context_build` — get full project context
- `moma_memory_save` — save a memory manually
- `moma_guardlock_check` — check if action is allowed
